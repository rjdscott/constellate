# Security policy

This is a research/benchmark project with no production deployment and no
supported versions. Everything runs locally against a public dataset
(MovieLens ml-25m); there is no user data.

If you find a security issue worth reporting anyway (a dependency
vulnerability that matters here, or something in the API/MCP surface),
email **rob@rjdscott.com** rather than opening a public issue. You'll get a
reply within a week.
